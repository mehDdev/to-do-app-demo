# 📝 To-Do List App

A simple application for managing daily to-do lists using React.
Data is fetched and managed as test data from JSONPlaceholder.

## ✨ Features
- Add, delete, and edit tasks
- Modal interface for adding/editing
- Filter by status (completed, not completed, all)

## 🛠 Built With

- [React](https://reactjs.org/) — JavaScript library for building user interfaces  
- [Vite](https://vitejs.dev/) — Next generation frontend tooling for fast development  
- [Tailwind CSS](https://tailwindcss.com/) — Utility-first CSS framework
- [React Router](https://reactrouter.com/) — For routing
